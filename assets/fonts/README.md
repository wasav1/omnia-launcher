# Omnia bundled fonts

These font files are bundled for the Omnia Plasma interface and loaded by `ui/qml/OmniaShell.qml`.

- Hanken Grotesk variable font: `HankenGrotesk.ttf`; SIL Open Font License 1.1 in `Hanken-OFL.txt`.
- Rajdhani weights 400, 500, 600 and 700; SIL Open Font License 1.1 in `Rajdhani-OFL.txt`.

Source: [Google Fonts](https://github.com/google/fonts), families `hankengrotesk` and `rajdhani`.
The respective font family and license notices are retained in the font metadata and license files.
